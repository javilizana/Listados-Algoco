## Para hacer correr los codigos:

- g++ NOMBRE_DEL_ARCHIVO.cpp -o NOMBRE_DEL_ARCHIVO
- ./NOMBRE_DEL_ARCHIVO

Para los casos en los que hay que poner input en un txt y no por terminal (como por ej en el A del L2):

- - g++ NOMBRE_DEL_ARCHIVO.cpp -o NOMBRE_DEL_ARCHIVO
- ./NOMBRE_DEL_ARCHIVO < in.txt
